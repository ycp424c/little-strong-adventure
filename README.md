# 小强历险记

一个使用 **React + shadcn/ui Button + Phaser 3** 开发的俯视角手动捕获生存小游戏。城市地图、主角、近战怪、远程怪、精英怪均由内置 imagegen 生成。

## 运行

```sh
npm install
npm run dev
```

开发预览：http://localhost:5173

```sh
npm test
npm run build
npm run preview
```

部署到子路径时，构建时传入完整路径（以 `/` 结尾），例如：

```bash
npm run build -- --base=/games/xiaoqiang/
```

将 `dist/` 作为静态文件发布。服务端应把无尾斜杠的路径重定向到带 `/` 的入口，去掉路由前缀后再查找文件，并启用 gzip 或 zstd。默认构建仍支持站点根路径；游戏素材、编队图标和 favicon 会跟随构建路径。

测试命令需要 Node.js 22.18+（原生 TypeScript type stripping）。构建结果位于 `dist/`，可部署至任意静态网站服务。

## 玩法

- 打开页面先看到加载进度：引擎脚本阶段显示不确定的扫光，素材阶段按已完成与在途文件推进（18%–96%），场景就绪后进度条收起，按钮变为“关店，回家！”。
- WASD / 方向键移动，空格冲刺，Esc / P 暂停；F / 鼠标左键手动捕获；触屏端用虚拟摇杆、捕获和冲刺按钮。
- 主角始终自动瞄准最近敌人（包括精英），并以淡虚线和目标圆环提示。走位切换最近目标，按 F / 鼠标左键单次发射皮搋子；按住不会连发。基础捕获射程 240、冷却 2.4 秒，冷却内不缓存出手，射程外不会消耗冷却。强化后射程最多 300，冷却最低 1.2 秒。普通怪命中即捕获；每次命中精英先扣血，归零后退化为一级普通怪，必须再次独立命中才能捕获。武器就绪时僚机会为附近普通怪让出靶位，并继续攻击精英。
- 近战怪主动接近、易于收编，成为生命较多但伤害较低的护卫；远程怪在 365–420 距离游走，并在玩家接近时后退，必须冒险接近或冲刺收编。远程僚机自动远射，射程 620、伤害更高，适配更多局面；所有僚机有独立生命，可能战死。
- **3 个同类型、同等级僚机自动合成下一等级，最高 3 级**。3 级近战获得大范围攻击，3 级远程获得三发散射。
- 编队初始 6 个位置，可强化至 10 个；满编仍允许第三只同类加入并立即合成。无法合成的多余捕获转为全队回复和经验。
- 五个街区各持续 2 分钟，每分钟有以远程为主的怪物潮。20 秒后增加常规刷怪数量，随机远程占比从 42% 逐步提高至 70%；4 分钟后远程怪开始三发散射。敌方子弹上限为 180，避免持续叠加弹幕。
- **45 秒出现第一只震地精英，此后每 60 秒刷新，最多同时存在 3 只**。新精英按当前存活僚机的最高等级生成（1–3 级，空队为 1 级），已有精英等级固定；血量、砸地范围和伤害随等级增强，生命仍随时间与编队战力增加。每只携带 2–5 只远程增援；敌群满员时仍保留定时精英的刷新机会。
- 精英只追击和砸地：固定位置蓄力 1.2 秒，红圈显示伤害范围；蓄力结束时，对圈内主角与僚机结算一次群伤，再收招 0.8 秒。提前离开红圈或在落地瞬间冲刺免伤，趁收招集火；僚机会尝试自行撤出预警圈。砸地有抬手、保持、落拳、回弹动作，以及震波、裂纹、尘屑和音画反馈；暂停与升级冻结技能和地面动画。
- 精英护甲归零时获得 4 经验，在原地退化为一级普通怪并取消砸地；致命命中本身不会同时捕获。退化用 0.65 秒的护甲残影、光圈与角色渐变表现，暂停同步冻结。退化后 3.2 秒内僚机暂不攻击它，给武器冷却和再次捕获留出时间；保护结束后恢复普通怪规则。破甲不再保证掉落血包。
- 血包首次于 40 秒尝试刷新，之后每 60 秒尝试刷新；普通击杀掉落率从 8% 降到 2%，全部来源共用至少 20 秒的生成间隔，场上最多 2 个。街区一次性补给及生命强化保持原规则。
- 黄色目标标记提供一次街区补给，绿色十字回复生命；升级时从三项强化中选择，选择期间时间冻结。
- 生存到 10:00 后，前往地图最右侧的家（小地图房子标记）获胜。提前到家仍需守到 10:00。

## 代码

- `src/game/model.ts`：与渲染无关的模拟、捕获、合成、战斗、难度、路线与胜负判定。
- `src/game/scene.ts`：Phaser Scene、输入、相机、Sprite 同步、视觉反馈与 Web Audio 音效；`preload` 期间把已完成、失败与在途文件折算成固定分母的整体进度上报给 React。
- `src/game/loading.ts`：启动进度的纯逻辑，把引擎脚本、素材下载与场景就绪折算成百分比和阶段文案；聚合用固定分母，配合界面的单调守卫避免回退。
- `src/App.tsx`：React HUD、编队、菜单、升级、虚拟摇杆。
- `assets/source/`：生成原图；`public/assets/`：部署用地图和透明 Sprite。
- `docs/asset-prompts.md`：内置 imagegen 的完整提示词与素材来源。
- `scripts/prepare-assets.mjs`：原图切片及压缩，可重复运行。
- `scripts/prepare-map-assets.mjs`：将 imagegen 重绘的六块高清地图编码为 WebP，并用原图锁定拼接边缘。合计原生像素为 5322×1774（旧版 2172×724 的约 6 倍像素），在 5400×1800 的世界中接近 1:1 显示；每块 1774×887，避免单张超宽纹理。地图和碰撞布局不变。
- `scripts/prepare-animation-assets.mjs`：生成图切成 8 方向行走（每方向 6 帧）、攻击（每方向 4 帧）及三类投射物（各 6 帧）图集，统一人物比例与脚底位置；原图和完整提示词在 `assets/source/`。
- `src/game/animation.ts`：主角与怪物共用带 6° 滞回的八方向选择，避免分界角附近来回跳行动画；明显转向立即响应。包含移动/攻击状态、退化过渡、受击抖动及投射物帧选择；所有反馈跟随战斗暂停，冲刺加快主角步频。
- 怪物图集每类 64 帧（8 方向 × 4 帧移动 / 4 帧攻击）。震地精英使用独立的 64 帧图集，包含八方向行走与四阶段砸地；僚机沿用原普通怪物动作。友方采用青蓝描边、圆形底环和箭头，敌方采用珊瑚红描边与菱形底框。三级仍保留金色等级点。
- 主角、敌怪和僚机受到真实伤害时闪白、短促抖动并出现扩散冲击与伤害读数；击倒或捕获后冲击仍会播放，免伤期间不会产生伪受击。反馈只作用于画面，不改变碰撞和战斗数值。
- `tests/elite.test.ts`：精英等级与成长、破甲退化后再次捕获、补刀保护及暂停过渡、定时刷新与上限、红圈群伤与闪避、僚机撤离及弹幕预算。
- `tests/supplies.test.ts`：降低后的定时补给、掉落率、共享生成间隔、场上上限及暂停计时。
- `tests/combat-feedback.test.ts` / `tests/monster-assets.test.ts`：覆盖近战与子弹受击、免伤、暂停、怪物攻击触发、八方向帧区间以及图集透明边界。
- `tests/game.test.ts`：手动触发与冷却、自动瞄准、合成封顶、满编合成、暂停、碰撞、胜利与完整时长压力测试。
- `tests/loading.test.ts`：加载百分比的区间映射、事件序列单调性、固定分母聚合、异常值夹紧和各阶段文案切换。

本游戏无后端、无账号、无付费、无数据上传。声音偏好仅保存在浏览器本地；关闭标签页不保留本局进度。Phaser 在进入页面后异步加载，开局前的进度条按实际完成的素材推进，素材就绪后自动收起。
