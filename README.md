# 小强历险记

一个使用 **React + shadcn/ui Button + Phaser 3** 开发的俯视角自动攻击生存小游戏。城市地图、主角、近战怪、远程怪、精英怪均由内置 imagegen 生成。

## 运行

```sh
npm install
npm run dev
```

开发预览：http://localhost:5173

```sh
npm test
npm run build
npm run preview
```

测试命令需要 Node.js 22.18+（原生 TypeScript type stripping）。构建结果位于 `dist/`，可部署至任意静态网站服务。

## 玩法

- WASD / 方向键移动，空格冲刺，Esc / P 暂停；触屏端用虚拟摇杆与冲刺按钮。
- 主角自动瞄准最近的敌人并发射带绳索的皮搋子，普通怪初始命中即捕获，后期护甲逐渐增加。
- 近战僚机自动追击并护卫，远程僚机自动射击；僚机有独立生命，可能战死。
- **3 个同类型、同等级僚机自动合成下一等级，最高 3 级**。3 级近战获得大范围攻击，3 级远程获得三发散射。
- 编队初始 6 个位置，可强化至 10 个；满编仍允许第三只同类加入并立即合成。无法合成的多余捕获转为全队回复和经验。
- 五个街区各持续 2 分钟，每分钟有怪物潮。精英、怪物数量、移速、护甲随进程上升。
- 黄色目标标记提供一次街区补给，绿色十字回复生命；升级时从三项强化中选择，选择期间时间冻结。
- 生存到 10:00 后，前往地图最右侧的家（小地图房子标记）获胜。提前到家仍需守到 10:00。

## 代码

- `src/game/model.ts`：与渲染无关的模拟、捕获、合成、战斗、难度、路线与胜负判定。
- `src/game/scene.ts`：Phaser Scene、输入、相机、Sprite 同步、视觉反馈与 Web Audio 音效。
- `src/App.tsx`：React HUD、编队、菜单、升级、虚拟摇杆。
- `assets/source/`：生成原图；`public/assets/`：部署用地图和透明 Sprite。
- `docs/asset-prompts.md`：内置 imagegen 的完整提示词与素材来源。
- `scripts/prepare-assets.mjs`：原图切片及压缩，可重复运行。
- `tests/game.test.ts`：自动捕获、合成封顶、满编合成、暂停、碰撞、胜利与完整时长压力测试。

本游戏无后端、无账号、无付费、无数据上传。声音偏好仅保存在浏览器本地；关闭标签页不保留本局进度。Phaser 在进入页面后异步加载。
